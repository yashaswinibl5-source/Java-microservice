13. Short Interview Answers You Can Practice
281. What is Spring Boot?
Answer: Spring Boot is a framework that simplifies Java application development by providing auto-configuration, embedded servers, and production-ready defaults.
282. What is REST?
Answer: REST is an architectural style for designing web services using HTTP methods and stateless communication.
283. What is gRPC?
Answer: gRPC is a high-performance RPC framework that uses HTTP/2 and Protobuf for strongly typed communication between services.
284. Why use Docker?
Answer: Docker helps package and run applications consistently across environments and makes service orchestration easier.
285. Why did Docker localhost fail?
Answer: Inside a container, localhost refers to the container itself, not another service. We used service names like postgres and billing-service.
286. What was the main bug in your project?
Answer: The gRPC dependency mismatch caused startup failure, which was resolved by aligning versions and rebuilding containers.
287. Why did you use DTOs?
Answer: DTOs separate API contracts from database entities and help validate and transfer required fields safely.
288. What is the role of validation?
Answer: Validation ensures the incoming request is complete and valid before data reaches the database or downstream service.
289. What is your biggest learning from this project?
Answer: Real-world systems require not only writing code, but also understanding networking, dependency management, and integration debugging.
